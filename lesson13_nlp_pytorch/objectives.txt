1. What is NLP?
Natural Language Processing (NLP) is a branch of Artificial Intelligence that helps computers process, understand, and work with human language.

Examples include:
- Sentiment analysis — determining whether a review is positive or negative.
- Spam detection — identifying unwanted messages.
- Text classification — categorizing emails, news, or documents.
- Machine translation — translating between languages.
- Chatbots — processing questions and generating responses.

For this lesson, we'll build a sentiment analysis model using PyTorch.

Imagine a customer writes:
"The product is excellent. I really love it!"

Our model should predict Positive.

But if the customer writes:
"The product is terrible and disappointing."

Our model should predict Negative.

This is a binary text-classification problem, similar in concept to your earlier customer-churn classification project. The difference is that our input is text rather than a row of numerical customer features or an image.

6. Lesson 13.2 — Tokenization and vocabulary
Consider this sentence:

"I love this product"

We can split it into tokens:
sentence = "I love this product"tokens = sentence.lower().split()print(tokens)



Output:
['i', 'love', 'this', 'product']


Tokenization is the process of breaking text into smaller units called tokens. Here, each token is a word.

Next, we build a vocabulary that assigns each unique word a numerical ID.

For example:
Word	Token ID
<PAD>	0
<UNK>	1
i	2
love	3
this	4
product	5

<PAD> is used to make sequences the same length, while <UNK> represents a word that is not in the vocabulary.

The sentence becomes:
"I love this product"
        ↓
[2, 3, 4, 5]


This is important because PyTorch's neural network cannot directly process ordinary words as input.

2. Create the vocabulary
A vocabulary is a dictionary mapping each known word to an integer ID.

We'll reserve two special tokens:
- <PAD> → 0: fills shorter sentences so a batch has consistent dimensions.
- <UNK> → 1: represents words not seen when the vocabulary was built.
For our small dataset, we'll build the vocabulary from the training texts. 
In a real project, it's important to build it from training data only to avoid leaking information from the validation or test set.
