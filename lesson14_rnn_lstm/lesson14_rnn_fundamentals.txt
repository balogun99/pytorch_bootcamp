Let's understand these dimensions.

Input shape: [2, 4, 5]
Dimension	Value	Meaning
First	2	Two sequences in the batch
Second	4	Four time steps per sequence
Third	5	Five features at each time step

Output shape: [2, 4, 10]

The RNN produces a hidden representation of size 10 for every time step in each sequence.

Final hidden state shape: [1, 2, 10]
- 1: One RNN layer.
- 2: Two sequences.
- 10: Ten hidden-state values per sequence.
Notice that the output contains a hidden representation for every time step, whereas the final hidden state contains the last hidden representation for each sequence.

-0.5515, -0.3394, 0.4488, 0.9006, ...

These are learned representations generated by the RNN.

They are not class labels, probabilities, or predictions.

The values are calculated from the input data, the RNN's weights, its biases, and its previous hidden state.

Also, grad_fn=<StackBackward0> indicates that PyTorch is tracking the computation for automatic differentiation. This is normal because you haven't disabled gradient tracking.

14.5 — Understanding the Limitations of Traditional RNNs
Traditional RNNs have a significant limitation: the vanishing gradient problem.

Imagine a sentence containing 100 words.

The model processes the words sequentially. Information from earlier words must pass through many recurrent steps before influencing later predictions.

During training, gradients can become extremely small as they travel backwards through those steps.

This makes it difficult for traditional RNNs to learn long-term dependencies.

For example:
The movie, which I watched several weeks ago with my friends, was absolutely fantastic.

The model may struggle to retain important information from the beginning of a long sequence.

This problem motivated the development of more advanced recurrent architectures.
14.6 — Introduction to Long Short-Term Memory (LSTM)



Long Short-Term Memory (LSTM) is an improved recurrent neural network architecture designed to capture information over longer sequences.

It introduces a special memory mechanism called the cell state.

An LSTM uses three main gates:
Gate	Responsibility
Forget gate	Determines what information to remove
Input gate	Determines what new information to store
Output gate	Determines what information to expose as output

Think about these gates as a memory management system.
- Forget gate: What should I forget?
- Input gate: What should I remember?
- Output gate: What information should I use now?
Unlike a traditional RNN, an LSTM has two state outputs:
1. Hidden state (ht)
2. Cell state (ct)
The cell state helps information travel through longer sequences with less difficulty than in a basic RNN.

We'll explore each gate mathematically and implement it in PyTorch in the next section.

Let's compare what we've learned.
